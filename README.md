# Orbit Siege (ต้นแบบ)

เกมยิงปืนใหญ่ผลัดตาธีมอวกาศ ทำด้วย **Godot 4.2** (GDScript ล้วน ไม่มี asset ภายนอก)
ทีมนักบินอวกาศ 3 คนของคุณ สู้กับบอท 3 คน บนดาวเคราะห์น้อยที่ระเบิดพังได้

**เล่นบนเว็บ:** https://pid924.github.io/OrbitSiege/ (ต้องเปิด GitHub Pages จากโฟลเดอร์ `/docs` ก่อน)

## วิธีเปิด
1. เปิด Godot 4.2 > Import > เลือกไฟล์ `project.godot` ในโฟลเดอร์นี้
2. กด F5 (Run Project)

ดูบอทสู้กันเอง (โหมดสาธิต): Project > Project Settings > Editor > Run > Main Run Args ใส่ `-- --autoplay`
หรือรันจาก command line: `godot --path . res://scenes/main.tscn -- --autoplay --stage=drift` (หรือ `--stage=titan`, `--stage=orbit`)

## ด่าน
เลือกได้จากหน้าเมนูตอนเปิดเกม (คลิก หรือกด 1-3)
1. **Asteroid Drift**: เกาะหินลอยกลางอวกาศ แรงโน้มถ่วงดึงลงล่าง ตกลงไปในดาวแก๊สยักษ์ด้านล่าง = ตาย
2. **Titan Shelf**: ฉากใหญ่พิเศษ แผ่นดินลอยฟ้าผืนยักษ์ ช่องว่างแคบ ร่วงยาก กล้องเลื่อนตาม ใช้ล้อเมาส์ซูมดูทั้งฉาก
3. **Orbit Field**: ดาวเคราะห์น้อยหลายดวง แต่ละดวงมีแรงโน้มถ่วงของตัวเอง

ตัวละครเดินตกขอบเองไม่ได้ (เดินไปถึงขอบผาจะหยุด) จะร่วงก็ต่อเมื่อพื้นใต้เท้าโดนระเบิดหายไปเท่านั้น

## ตัวเลือกก่อนเริ่ม (หน้าเมนู)
- **เส้นนำวิถีกระสุน**: ปิด / สั้น / กลาง / ยาว / เต็มเส้น แสดงเส้นจุดว่ากระสุนจะวิ่งไปทางไหน (คิดแรงโน้มถ่วงและลมแล้ว) ยิ่งยาวยิ่งเล่นง่าย
  ก่อนชาร์จ เส้นจะใช้แรงจากนัดก่อนหน้า ระหว่างกด SPACE ค้างจะเปลี่ยนตามแรงที่ชาร์จ
- **ความเร็วแถบชาร์จ**: เร็ว (1.6 วิ) / ปกติ (2.6 วิ) / ช้า (3.6 วิ) / ช้ามาก (5 วิ) เวลาที่กด SPACE ค้างจนเต็ม
- **ความยากบอท**: ง่าย / ปกติ / ยาก

ค่าเริ่มต้น: เส้นนำวิถีเต็มเส้น, แถบชาร์จปกติ, บอทง่าย

## กล่องเสบียง
ทุกครั้งที่ทุกคนที่ยังมีชีวิตได้เล่นครบคนละ 1 ตา จะมีกล่องกางร่มตกลงมาจากฟ้าตรงตำแหน่งสุ่ม (ตกลงช่องว่างก็หายไป) เดินไปแตะเพื่อเก็บ ข้างในสุ่มได้ 1 อย่าง:
- ฮีล 35 HP ให้ตัวที่เก็บ
- อาวุธพิเศษสุ่ม +1 นัดให้ทั้งทีม
- นัดถัดไปของทีมแรงขึ้น 25%

บนแผนที่มีกล่องได้พร้อมกันสูงสุด 4 กล่อง

## เหตุการณ์สุ่มรายเทิร์น
แต่ละเทิร์นมีโอกาส 40% ที่จะเกิดเหตุการณ์ 1 อย่าง (ขึ้นป้ายตอนเริ่มเทิร์น และแสดงใต้ชื่อด่านตลอดเทิร์น):
- ทุกนัดในเทิร์นนี้แรงขึ้น 10% (ดาเมจ)
- ทุกนัดในเทิร์นนี้เบาลง 10% (ดาเมจ)
- เวลาเทิร์นนี้ลดลง 5 วินาที / เพิ่มขึ้น 5 วินาที
- ระเบิดเทิร์นนี้กว้างขึ้น 10% (หลุมและวงดาเมจ)

## กลไกหลัก
- **แรงโน้มถ่วงดาวเคราะห์**: ดาวทุกดวงดึงกระสุน ยิงอ้อมดาวหรือใช้ดาวเหวี่ยงวิถีได้ ตัวละครยืนได้รอบดาว ("ข้างบน" คือทิศออกจากดาว)
- **ลมสุริยะ**: แรงผลักคงที่ เปลี่ยนทิศ/ความแรงทุกตา ดูที่มาตรวัดมุมขวาบน
- **พื้นทำลายได้**: ระเบิดเจาะพื้นเป็นหลุม ระเบิดไม่ทำให้ตัวละครกระเด็น แต่ถ้าพื้นใต้เท้าหายก็ร่วง ตกลงไปด้านล่างในด่านเกาะลอยฟ้า = ตาย
- **บอท**: จำลองวิถีกระสุนหลายร้อยแบบด้วยฟิสิกส์ชุดเดียวกับเกม เลือกนัดที่ใกล้ศัตรูสุดและไม่โดนพวกเดียวกัน แล้วใส่ความคลาดเคลื่อนเล็กน้อย
  ปรับความยากได้ที่ `angle_error_deg` และ `power_error` ใน `scripts/controllers/bot_controller.gd` (ค่าน้อย = เก่ง)

## เตรียมไว้สำหรับออนไลน์
ทุกการกระทำที่เปลี่ยนเกม (เดิน เล็ง เปลี่ยนอาวุธ ยิง) ส่งเป็น Dictionary ผ่าน `match.submit_command()` ที่เดียว
ทั้งผู้เล่นและบอทใช้ทางนี้อยู่แล้ว ส่วนฟิสิกส์คำนวณแบบ fixed step ใน `match._physics_process()` ที่เดียว

ตอนทำออนไลน์ แนวทางที่แนะนำ:
1. ให้ host เป็นเจ้าของเกม (authoritative) ใช้ `ENetMultiplayerPeer` หรือ `WebSocketMultiplayerPeer`
2. เพิ่ม `NetworkController` ฝั่ง client ที่ส่งคำสั่ง Dictionary เดิมผ่าน RPC ไปหา host แทนการเรียก `submit_command()` ตรง ๆ
3. host ตรวจว่าเป็นตาของผู้ส่งจริง (`is_turn_of`) แล้ว apply และกระจายผล (ตำแหน่งตัวละคร, หลุมที่เจาะ, HP) กลับไป
4. `match_seed` ใช้สร้างแผนที่ ส่ง seed เดียวกันให้ทุกเครื่องก็ได้แผนที่เดียวกัน
